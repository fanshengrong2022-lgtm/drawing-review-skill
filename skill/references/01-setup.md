## 第零部分 · 第一次用 AI？先从这里开始

> **这一章是给"第一次接触 AI"的人写的。** 用得很熟的话，可以跳到第一部分。
> **但第 0.2 步（环境自举）建议无论谁先做一遍** —— 环境没搭好，后面全是空转。

## 0.1 先弄清你的 AI 是哪一类

| 你的 AI 是 | 怎么用这份文件 |
|---|---|
| **能读写文件、能跑命令**（带"Agent / 智能体"字样的工具，如 Trae / CodeBuddy / Claude Code / WorkBuddy / Cursor 等） | ⭐ **让它把这份文件装成技能**（见下） |
| **只能网页对话**（网页版 AI、手机 App） | **整份复制粘贴进去**，然后说"**按这份 skill 帮我审图**" |

### 装成技能 —— 把这段话复制给它

```
把这份文档完整原样保存为我的本地技能文件：
  文件名：SKILL.md        （这是平台要求的固定名字，靠目录名区分）
  目录名：审图Skill
  放在你这个平台默认的技能目录下（你不知道放哪的话，
  先告诉我你的技能目录在哪，再存）

要求：一字不改、不删、不增、不重排。只做"复制"，不要"总结/改写/拆分"。
保存后告诉我：原文总字数应为 N，实际保存 N，是否一致。
```

> ⚠️ **为什么要报字数**：不一致就说明它偷偷改了。**这是最简单的防失真办法。**
> **装好之后，你以后不用再贴文件** —— 直接跟它说"审图"，它就知道该用这套流程。

## 0.2 ⭐ 环境自举 —— 把下面这段整段发给你的 AI

```
帮我先把审图环境搭好，搭完再开工。

【第一步 · 先自检，别猜，实际检查】
逐项报告：
1. 这台机器有没有 Python？版本多少？（要 3.8 以上）
   ⭐ **如果没有，不要跳过去** —— 请直接告诉我怎么装（按我的系统给步骤：Windows 还是 Mac）
2. 这几个 Python 库装了没：ezdxf、openpyxl、pymupdf、PyPDF2
3. 有没有 ODA File Converter（用来把 DWG 转成 DXF）？
   ⭐ **如果没有，先别急着让我装** —— 先告诉我"不装它还有哪些替代办法"

【第二步 · 缺什么装什么】
- Python 库缺的，直接装（一行装齐）：
    pip install ezdxf openpyxl pymupdf pypdf
  （`pypdf` 是 PDF 库的新名字，旧名叫 `PyPDF2` —— 如果上面提示找不到 pypdf，
   就改装 `pip install PyPDF2`，**两者装一个就够**）
  如果下载慢或失败，换国内镜像重试：
    pip install -i https://pypi.tuna.tsinghua.edu.cn/simple ezdxf openpyxl pymupdf pypdf
- ODA File Converter 是桌面软件，你装不了。请告诉我：
  · 它的下载地址和安装步骤
  · 以及"如果我不装它，还有别的办法把 DWG 变成 DXF 吗"

【第三步 · 装完复检，给我一张表】
| 依赖 | 状态 | 版本 / 说明 |
告诉我：哪些好了、哪些没装成、没装成卡在哪一步。

【第四步 · 然后告诉我，以我现在这套环境能走哪条路线】
A 线（DWG/DXF 数据线）｜ B 线（PDF 电子版）｜ C 线（扫描件 / 图片）
能走到哪条走哪条；走不了的，说明缺什么、怎么补。

【四条纪律】
- 不许跳过自检直接开始审图。环境不确认，后面结论不可信。
- 不许假装装好了。装不上就说装不上，说清卡在哪。
- 不许"大概能用"就往下走。用实际跑一遍的结果说话。
- 全程只做环境，不要动我的图纸文件。
```

## 0.3 装完怎么确认（30 秒）

把这条命令交给你的 AI，或者自己在命令行里跑：

```bash
python -c "
import sys; print('Python', sys.version.split()[0])
import importlib.metadata as md
for p in ['ezdxf','openpyxl','pymupdf','pypdf','PyPDF2']:
    try: print(p.ljust(10), 'OK', md.version(p))
    except Exception: print(p.ljust(10), '未安装')
"
```

**看到这四个好了就算齐了**：`ezdxf`（读 CAD）、`openpyxl`（读 Excel）、`pymupdf`（读 PDF/扫描件）、**`pypdf` 或 `PyPDF2`**（PDF 那两个**装一个就够**）。

缺哪个，回到第 0.2 步让它装。

> **这份 skill 不依赖任何其他 skill** —— 它只用**普通的 Python 库**和一个**免费桌面软件**。
> 这叫"**自包含**"：你不需要再装一堆别的东西，也不怕以后某个技能下架了就失效。
> 如果你的 Agent 技能库里**恰好**有现成的 CAD 或表格工具，顺手装上也可以；**但没有它照样能跑**。

## 0.4 你这套环境能走哪条线

| 你的环境 | 能走 | 精度 |
|---|:--:|:--:|
| Python ＋ 四个库 ＋ 有 DXF 图纸 | ⭐ **A 线** | ⭐⭐⭐⭐⭐ |
| Python ＋ 库 ＋ 只有 PDF 电子版 | **B 线** | ⭐⭐ |
| 只能网页对话 | **C 线**（贴文字 / 贴图） | ⭐ |
| 什么都没有，也不能跑命令 | 走 C 线，且**只能核对能抄成文字的那部分** | ⭐ |

> 三条路线具体怎么走、精度差在哪 → 见 **2.2**。

## 0.5 装不上？四条降级路线（别卡在这一步）

| # | 卡在哪 | 怎么办 |
|:-:|---|---|
| **1** | ⭐ **机器上根本没有 Python** | 让 AI 给你按系统分步骤的安装指引（去 python.org 下官方安装包，**安装时记得勾上"Add Python to PATH"**）。<br>**装完回来把上面那段自举指令重发一遍。** |
| **2** | **pip 装不上**（网络慢 / 权限报错） | ① 换国内镜像（上面第二条命令）② 用 `python -m pip` 代替 `pip` ③ 还是不行 → 让 AI 把它导成一个文件用别的机器装 |
| **3** | **ODA 装不上，或官网打不开** | ⭐ **不用 ODA 也行** —— 三条替代：<br>① **有 AutoCAD / 天正** → 打开图纸「**另存为**」→ 选 **DXF（低版本，如 2018）**，最省事<br>② **有 CAD 看图类工具** → 用它的导出 / 另存为功能<br>③ 都没有 → 走 **B 线**（向设计院要 **PDF 版**图纸） |
| **4** | **DWG 打不开 / 是天正加密图 / 版本太高** | 用 CAD 打开后另存为**低版本 DXF**；实在打不开，就让设计院导出 PDF 走 B 线 |
| **5** | ⭐ **AI 根本不能跑命令**（只能网页对话） | 走 **C 线**：把图纸里**能抄成文字的部分**整理给它 —— **设计说明、物料书、门窗表、图例表、材料统计表**。<br>**精度会降，但这几类照样能查**：核冲突（b 图↔物料书 / c 图↔规范 / d 图↔交底）、双边对应六对、编号与目录核对。 |

> **一句话**：**A 线是最强的一条，但不是唯一的一条。**
> 这五条卡点**没有一条能把你挡在门外** —— 装不上就退一条线，退到 C 线照样能出东西。
> **别让"装软件"这一步耗掉你一整晚。**
