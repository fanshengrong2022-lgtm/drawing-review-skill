## 三、怎么取（三种方式）

**方式 A · 命令行**

```bash
# 有哪些主题
python scripts/ask_api.py --method list

# 一次取全一个主题（推荐，少跑几次）
python scripts/ask_api.py --method self-check --all

# 先看分段，再取某几段
python scripts/ask_api.py --method self-check --outline
python scripts/ask_api.py --method self-check 10
```

**方式 B · 直接打接口**

```bash
curl -X POST "$DRAWING_REVIEW_API/v1/method" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $DRAWING_REVIEW_KEY" \
  -d '{"topic":"self-check","all":true}'
```

**方式 C · 取判据（按章，不按关键词瞎猜）**

```bash
python scripts/ask_api.py --checklist --profession 排水 --outline
python scripts/ask_api.py --checklist --chapter "P2 检查井" --limit 200
python scripts/ask_api.py --checklist --chapter "P2 检查井" --limit 200 --offset 200
```

## 四、⭐ 四条铁律

### 1. 动手前必须取，不许凭印象

**开工三件套（`preparation` / `five-steps` / `self-check`）没取完，不许开始看图。**
每做一步、每写一类内容，**先取对应的段**。
凭印象做出来的东西，句式不对、表格列不对、清单缺项 —— 等于白干。

### 2. 取到什么就按什么做

**表格列、句式、清单项、分级标准，全部照云端返回的来。**
不许自己发挥、不许"我觉得这样更好"。

### 3. 取不到就停

无 Key / 网络断 / 接口 402 / 接口超时 →
**明确告诉用户：「方法库取不到（原因），无法继续」，然后停下。**

⛔ **绝对不许**：自己编一套方法顶上、假装取到了、跳过某一步直接出报告。

### 4. 判据要按章取全，不许只查关键词

只查关键词 = 只查到你想到的。**先拿大纲（`--outline`）保证一章不漏，再用关键词定位。**

## 五、环境变量（只需配一个）

```bash
export DRAWING_REVIEW_KEY="<向作者申请的 Key>"
```

没有 Key 时，`--health` 能通（探活），其余全部返回 402。
联系方式见 `SKILL.md` 的「使用前须知」。
