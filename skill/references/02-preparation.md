## 第一部分 · 开工前准备（四件必做，一件都不能少）

## 准备 0：工作边界（碰图纸之前，先把规矩立好）

**用户最怕的不是"审不出来"，是"AI 乱翻我电脑"。这一节先把这个顾虑解决掉 —— 边界一次说清，后面才敢把图交给你。**

动手前必须和用户确认这四件事（**用户已经给了的，复述确认；没给的，问**）：

| # | 立什么边界 | 怎么做 |
|:-:|---|---|
| **1** | **图纸在哪** | 拿到**图纸目录的准确路径**；工作范围 = 该目录及其子目录 |
| **2** | **产出写到哪** | 约定**一个输出目录**；报告 / 中间文件 / 脚本**全部写这里** |
| **3** | **依赖怎么装** | 只装 `01-setup.md` 列出的那几个库；**不装无关工具、不下载额外东西** |
| **4** | **skill 只读** | ⛔ 不修改 `SKILL.md` 与 `references/` 下的任何文件 |

**【三条硬纪律】**

- ⛔ **不读图纸目录以外的文件** —— 个人文档、其他项目、桌面、下载夹…… **用户没让你看的，一律不看**
- ⛔ **不往系统目录写东西** —— 桌面 / 文档 / 临时夹都不写，只写约定的输出目录
- ⛔ **越界前先问** —— 确有必要访问其他位置，**先说理由、先征得同意**，再动

**开工第一句，先把边界说出来**：

```
我要审的图在：<路径>
产出我写到：<路径>
除这两处，我不访问其他位置；skill 文件我不改。
```

**为什么这一节排在准备 A 前面**：边界是**前提**，不是能力问题。
**能力不够只会漏报；边界不清，用户压根不敢把图交给你。**

---

## 准备 A：先划边界 —— AI 能做什么、不能做什么

**先让 AI 和你自己都建立合理预期。不划边界的审图，出来的报告不可信。**

### A1. 三分法（每条结论都要标类型）

| 类型 | 什么情况 | 输出要求 |
|---|---|---|
| ✅ **可靠执行** | 文字提取、跨图比对、关键词扫描、数值读取与简单计算、"有无"判断、索引检查 | 结果可直接采信 |
| ⚠️ **勉强执行** | 跨图空间位置叠加、构造层完整性、收口节点、预埋标注 | **必须打标【需人工复核】**，只给"疑似 + 依据"，**不给精确坐标** |
| ❌ **无法执行** | 需要图纸之外的信息、需要现场感知、需要管理判断 | **不强行判定**，转入人工清单 |

### A2. ⭐ 无法执行的 7 类 —— 一律报"C 类嫌疑"

以下情况**不下结论**，只报"需人工复核"：

| 情况 | 怎么报 |
|---|---|
| 识别到"扶手"但无法判断是否临空栏杆 | 报"位置不明确，需人工复核"**嫌疑**，**不报 A 类** |
| 识别到"标高冲突"但不确定是否同一空间 | 报"标高冲突嫌疑" |
| 识别到"尺寸冲突"但不确定是否同一构件 | 报"尺寸冲突嫌疑" |
| 识别到"构造层缺失"但不确定大样图是否已表达 | 报"构造信息待补充" |
| 识别到"材料等级缺失"但不确定说明里是否写了 | 报"材料等级待确认" |
| 识别到"机电点位尺寸缺失"但本专业不含此范围 | 报"待人工复核"（信息提取） |
| 识别到"玻璃栏板"但无高度标注、无位置上下文 | 报"高度待补充" |

> ## **报"我不确定"，比报一个错的强条有价值得多。**

> **⚠️ 这一节和「Z 类」不是一回事，别混**：
> **这里的 7 类** = AI **觉得可疑但拿不准** → 报**嫌疑**（进问题清单，标 C 类）
> **Z 类** = **图上根本没有答案、AI 压根判不了**（层高实际多少、厂家尺寸多少）→ **单独列表，不算 AI 成绩**（见第 4 步（4）第 5 张）

### A3. 人机协同工作流

```
第一步：AI 全图纸扫描
   ├── AI 擅长项 → 直接输出问题清单
   ├── AI 辅助项 → 输出嫌疑清单（打标）
   └── AI 无法项 → 输出《人工复核清单》
        ↓
第二步：人工针对性复核（只复核辅助项 + 无法项，不用从零看）
```

**角色定位（给 AI 的第一句话）**：

> 你是一个有经验的项目经理，做**图纸会审预审**。你的任务是查"错、漏、碰、缺"四类问题。
> **只报告图纸内可查证的问题** —— 凡需要现场实测、厂家资料或管理协调才能判定的事，一律不强行判定。

## 准备 B：问清立场（不可跳过）

**在碰图纸之前，必须问清立场。没问清就问，不要硬审。**

| # | 问什么 | 为什么 |
|:-:|---|---|
| 1 | **合同范围** | 界定责任范围 |
| 2 | **工程量清单** | 界定施工内容 |
| 3 | **工作面界限划分** | ⭐ **哪些范围是你的、哪些不是** |

> **没有立场的审图 = 全场乱报。**
> 同一张图，站在不同单位立场上，该管的事完全不同。

---

## 准备 C：数据自检（不齐不许出报告）

**料不全就先补料，绝不带着残缺数据出报告。**

**先做第 0 步：环境就绪确认**（第一次用 / 换了台机器 / 换了 AI，都要做一遍）

| 确认什么 | 达标 |
|---|---|
| **AI 会不会跑命令** | 会 → 能走 A 线；不会 → 走 B / C 线（见 0.4） |
| **Python 与库齐没齐** | `ezdxf / openpyxl / pymupdf / PyPDF2` 四个都 OK（自检命令见 0.3） |
| **DWG 转 DXF 有没有着落** | 有 ODA ｜ 或有 CAD/天正能另存为 DXF ｜ 或只能拿 PDF |
| ⭐ **结论：这次走哪条线** | **明确写出来**：A 线 / B 线 / C 线 —— 不许含糊 |

> **不知道该装什么 → 把第 0.2 节那段话整段发给 AI，它会自己列清单、自己装、装完汇报。**

**再查数据本身**：

| 查什么 | 达标 |
|---|---|
| 图纸齐不齐 | 该有的图都在；缺的列清单 |
| 物料书 / 设计说明 | 能不能读到内容 |
| 读不读得动 | 文件能不能解析（扫描件 / 加密 / 格式问题） |
| ⭐ **读取是否读全** | **Model + Paper 空间 / TEXT + MTEXT + ATTRIB / 属性块里的标高** —— 六处逐项确认（见 2.4 ②） |
| **转换失败多少** | 转不成的**张数要点出来**，不许无声跳过（见 2.6） |

**【铁律】**：
- 任何一项不达标 → **停止出报告，先说明缺什么、怎么补**
- ⭐ **数据明显异常要主动报警，不要静默失败**（例：物料编号一个都对不上，应该报"编号体系可能不匹配"，而不是默默输出"匹配 0 条"）
- ⭐⭐ **读到 0 条或极少时，先怀疑读取方式，再怀疑图纸** ——
  **顺序不许颠倒**。同一张图，换一个空间 / 换一个实体类型就是满的。
  **下"图纸没写"这种结论之前，先把六处排除一遍。**
