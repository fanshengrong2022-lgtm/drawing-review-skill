# 第三部分 · 执行（五步）★核心

> **本文件只给流程骨架。五步的具体做法全部在云端方法库，必须按步取用。**
> 取用方式见 `references/00-索引.md`。

## 五步总览

| 步 | 做什么 | 交付什么 | 云端段号 |
|:-:|---|---|:-:|
| **1** | 定标准：审图拿什么当依据 | 自己的规范库 | **2** |
| **2** | 叠图：把多册图对到同一基准 | 轴网基准 + 执行分层 | **3** |
| **3** | 核冲突：跨图逐项比对 | 《跨图比对表》 | **4** |
| **4** | 出报告：写成能上会的报告 | 三张汇总表 + 销项表 + 兜底清单 | **5** |
| **5** | 迭代：把经验喂回来 | 更新规范库 | **6** |

## ⚠️ 执行纪律（三条，不许跳）

1. **每一步动手前，先取该步的详细做法** —— 不许凭印象做、不许跳过取用。
2. **取到什么就按什么做** —— 报告里的表格列、句式、清单，全部按云端返回的来。
3. **取不到就停** —— 无 Key / 断网 / 接口报错 → 明确告诉用户「方法库取不到，无法继续」，**不许自己编一套顶上**。

## 怎么取

```bash
python scripts/ask_api.py --method five-steps 2    # 第 1 步·定标准
python scripts/ask_api.py --method five-steps 3    # 第 2 步·叠图
python scripts/ask_api.py --method five-steps 4    # 第 3 步·核冲突
python scripts/ask_api.py --method five-steps 5    # 第 4 步·出报告
python scripts/ask_api.py --method five-steps 6    # 第 5 步·迭代
```

先看目录再取正文：

```bash
python scripts/ask_api.py --method five-steps --outline
```

## 五步之间的关系（框架级）

```
1 定标准 ──┐
           ├─→ 2 叠图 ──→ 3 核冲突 ──→ 4 出报告 ──→ 5 迭代回 1
资料齐备 ──┘
```

**没有第 1 步的标准，第 3 步判不了"冲突"；没有第 2 步的基准，第 3 步对不上位置。**
顺序不能颠倒，但可以在第 2 步之后暂停（出一版中间结果给人看），再继续。
