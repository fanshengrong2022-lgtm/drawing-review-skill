# 第二部分 · 技术路径（图纸怎么变成 AI 能读的东西）

> **本文件只给路线骨架。具体转换怎么跑、踩过哪些坑，在云端方法库。**
> 取用方式见 `references/00-索引.md`。

## 一句话路线

```
DWG / DXF / PDF  →  AI 能读的结构化数据（文字 / 尺寸 / 图层 / 物料编号）  →  按五步审
```

## 三条路线（先看你手上的图纸是什么格式）

| 路线 | 输入 | 适用 | 需要什么 |
|:-:|---|---|---|
| **A** | DWG / DXF | 有原始 CAD 文件（最好） | 本地要有 CAD 转换工具 |
| **B** | 矢量 PDF | 只有出图 PDF，但文字层还在 | PDF 解析工具 |
| **C** | 扫描 PDF / 图片 | 只有晒图或截图 | OCR + 视觉读图 |

**A 线最准，C 线最不稳。选哪条取决于你手上有文件。**

## ⚠️ 执行纪律

**动手转换前，必须先取该主题的详细做法**（含环境要求、已知限制、失败时的降级路线）：

```bash
python scripts/ask_api.py --method tech-path --outline   # 先看分段
python scripts/ask_api.py --method tech-path 4           # 转换流程（最长的一段）
python scripts/ask_api.py --method tech-path 7           # 已知限制
```

**取不到就停下来问用户要什么格式的文件，不许瞎猜、不许说"读不到就是没有"。**

## 读图的两条底线

1. **读不到 ≠ 没有** —— 读不到只能写「待核」。
2. **先体检再判断** —— 用 `scripts/health_check.py` 跑一遍，体检不过先修，别急着审。
