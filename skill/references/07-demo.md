## 一条完整示范

> 示范给这 1 条，把**格式和思路**立成标准样板。**其余条目照这个格式，用第 5 步从你自己的项目里长出来。**

### `M-02` ｜ 厨房无排水管接口

| 字段 | 内容 |
|---|---|
| **部位** | 厨房 |
| **检查内容** | 厨房有给水（洗菜盆 / 水槽）但无排水支管（DN50 / DN75）标注 |
| **判据** | **有给水、无排水 → 判定缺排水接口** |
| **依据** | 〔**填你自己的规范依据 —— 怎么得到，见第 1 步「（1）建你自己的规范库」**〕 ｜ 来源：一次真实图纸会审发现 |
| **等级** | A 类（阻断级） |

- **为什么容易出事**：厨房给水排水是两套系统，画图的人容易只画给水就收工。
- **后果**：现场干到一半发现没有排水口 → 打楼板 / 外墙 → 返工 + 渗漏隐患。
- **怎么查**：翻到厨房平面图 → 找"洗菜盆 / 水槽" → 顺着找有没有排水支管标注 → **只有给水管、没有排水管，就是它**。
